# 🐍 Snake Game using Python & Pygame

A classic Snake Game built using **Python** and **Pygame** with background music, sound effects, custom graphics, and smooth gameplay.

---

## 🎮 Game Features

- Smooth snake movement
- Custom snake head and body design
- Background music (looped)
- Food eating sound effect
- Game over sound effect
- Custom background image
- Pause and resume functionality
- Score display system

---

## 🕹️ Controls

| Key | Action |
|-----|--------|
| ⬅️ Left Arrow | Move Left |
| ➡️ Right Arrow | Move Right |
| ⬆️ Up Arrow | Move Up |
| ⬇️ Down Arrow | Move Down |
| SPACE | Pause / Resume |
| C | Play Again |
| Q | Quit Game |

---

## 🧠 Game Rules

- The snake grows after eating food
- Score increases by **10 points** for each food eaten
- Game ends if the snake:
  - Hits the wall
  - Collides with itself
